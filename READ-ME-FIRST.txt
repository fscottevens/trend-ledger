STONKS RUN - INDEX EXPANSION + LAUNCH READINESS  (update of Nov 5, 2026)
=======================================================================

WHAT CHANGED
------------
1. The screen now covers six indexes, each stock once:
     S&P 500 (503) - S&P MidCap 400 (400) - Nasdaq-100 (101)
     Dow Jones Industrial Average (30) - Dow Transportation (20) - Dow Utilities (15)
   = 919 unique tickers (was 902, of which 15 had left their index and 30
   current members were missing - e.g. RDDT, MRVL, HUBS, TOST, ROKU, FERG).
   Membership lives in universe/index_members.json and is re-checked about
   once a week by the workflow, with safety checks. Nothing to maintain by
   hand except the Dow 30 (the run summary warns you when it changes,
   roughly once a year).
2. New pages: stonks.run/indexes/ plus one per index (/indexes/dow-30,
   /indexes/nasdaq-100, ...), an Index Scoreboard on the home page, and index
   badges on every stock page and pop-up.
3. Launch fixes (details in the "Global launch readiness review" doc):
   - "Passing Trend Template" now shows stocks passing ALL 8 criteria; the
     screen's looser 6-of-8 gate is labelled as such.
   - Yahoo's business descriptions and analyst ratings/price targets are no
     longer published (licensing + "reads like advice" risk). Each stock gets
     a one-line profile written by the site from facts instead.
   - Fonts are served from stonks.run, not Google Fonts (EU privacy rule).
   - Privacy policy and terms updated for visitors outside the US; a
     "Privacy & cookie settings" link in every footer.
   - Accessibility: low-contrast grey text fixed, heading order, ARIA.
   - Security headers against click-jacking; a 30-day backup of the scan
     history on every run.
   The rankings themselves are unchanged on purpose.

Steps 2-6 work from a phone browser. Step 1 needs the computer.


STEP 1 - PUT THE UPDATE ON GITHUB  (computer, ~3 minutes)
---------------------------------------------------------
The new files are already in C:\Users\fscot\Documents\trend-ledger.
Open a Command Prompt there:

  cd C:\Users\fscot\Documents\trend-ledger
  git pull
  copy /Y scan.yml.COPY-INTO-.github-workflows .github\workflows\scan.yml
  findstr /C:"Refresh index membership" .github\workflows\scan.yml
  git add -A
  git commit -m "Add Nasdaq-100 and Dow Jones indexes, index pages, launch fixes"
  git push

The findstr must print a line. If it prints nothing, the copy failed - stop.
If "git pull" complains that a file in docs\data would be overwritten, run
  git checkout -- docs/data
and then "git pull" again.


STEP 2 - RUN IT ONCE AND CHECK THE PREVIEW  (~10 minutes, mostly waiting)
------------------------------------------------------------------------
1. https://github.com/fscottevens/trend-ledger/actions > "Scheduled scan"
   > Run workflow > Run workflow.
   The first run downloads company data for ~45 new stocks, so it can take
   a few minutes longer than usual.
2. When it is green, open https://stonks-run.fscottevens.workers.dev and check:
     - the home page has the "Index Scoreboard" near the bottom
     - https://stonks-run.fscottevens.workers.dev/indexes/ lists six indexes
     - a stock page (e.g. /stock/msft) shows S&P 500, Nasdaq-100 and Dow 30 badges
3. If you set a repository VARIABLE called EXTRA_TICKERS earlier (for the
   Nasdaq names), delete it: Settings > Secrets and variables > Actions >
   Variables. The Nasdaq-100 is built in now. (Leaving it does no harm.)


STEP 3 - FLIP THE SWITCH TO CLOUDFLARE  (2 minutes + a few minutes for DNS)
--------------------------------------------------------------------------
stonks.run is still served by GitHub Pages, so Google and AdSense don't yet
see the stock pages, index pages or the pre-rendered lists.
1. https://github.com/fscottevens/trend-ledger/settings/variables/actions
   > New repository variable
       Name:  SITE_HOST
       Value: cloudflare
2. Actions > "Scheduled scan" > Run workflow again.
3. When it is green, open https://stonks.run/indexes/ . If it loads, stonks.run
   is served by Cloudflare. Give it 5 minutes and refresh if it 404s at first.

IF SOMETHING LOOKS WRONG AFTER THE SWITCH (rollback)
  a. Delete the SITE_HOST variable (or set it to github).
  b. Cloudflare > Workers & Pages > stonks-run > Settings > Domains & Routes:
     remove stonks.run and www.stonks.run.
  c. Cloudflare > stonks.run > DNS: add back the GitHub Pages records
       A     stonks.run  185.199.108.153   (and .109.153, .110.153, .111.153)
       CNAME www         fscottevens.github.io


STEP 4 - AFTER THE SWITCH  (~15 minutes)
----------------------------------------
A. Turn off GitHub Pages:
   https://github.com/fscottevens/trend-ledger/settings/pages > Source: None.
B. www -> main address: Cloudflare > stonks.run > Rules > Redirect Rules >
   Create rule > template "Redirect from WWW to root" > Deploy.
   Then SSL/TLS > Edge Certificates > "Always Use HTTPS" > On.
C. Analytics (free, no cookies): Cloudflare > Analytics & Logs >
   Web Analytics > Add a site > stonks.run > automatic setup.
D. Google Search Console: https://search.google.com/search-console >
   Add property > Domain > stonks.run > verify through Cloudflare.
   Then Sitemaps > enter  sitemap.xml  > Submit.


STEP 5 - ADSENSE CONSENT MESSAGES  (the last item before resubmitting)
---------------------------------------------------------------------
AdSense > Privacy & messaging:
  - European regulations > Create message > choose stonks.run > Publish.
    Required to show ads to visitors in the EU/EEA, UK and Switzerland.
  - US state regulations > Create message > stonks.run > Publish.
    Shows the "Do not sell or share" opt-out the privacy policy describes.
Both use the AdSense code already on every page; nothing to change in the
site. The footer link "Privacy & cookie settings" reopens the message.
(If you sign in to Google in the Claude app's browser, Claude can do this.)


STEP 6 - REQUEST THE ADSENSE REVIEW
-----------------------------------
AdSense > Sites > stonks.run > Request review. Best done a few days after
Step 3 so Google has crawled the new pages (Search Console > Pages shows it).
Strongly recommended before you submit: put your real name (or an LLC name)
and a two-line bio on the About page. Finance sites are held to a higher
trust bar, and the privacy policy should name who runs the site.

INDEX MEMBERSHIP (for reference)
--------------------------------
Each week the workflow step "Refresh index membership" compares the lists
with Wikipedia's constituent tables (S&P 500, S&P 400, Dow Transports, Dow
Utilities) and Nasdaq's own Nasdaq-100 list. A list that looks wrong (too
many changes at once, wrong count, odd symbols) is ignored and last week's is
kept; you'll see a yellow warning on the run summary. When the summary says
the Dow 30 changed, edit the DJIA tickers in universe/index_members.json,
update its "checked_at" date to today, and push.


THE SCAN SCHEDULER (unchanged, for reference)
--------------------------------------------
The Cloudflare Worker "stonks-run-scheduler" starts each scan on time. Its
GitHub token expires about a year after Sept 2026. When the Worker's page
(https://stonks-run-scheduler.fscottevens.workers.dev) shows the token as
MISSING or ERROR:
  1. https://github.com/settings/personal-access-tokens/new
     Repository access: only trend-ledger. Permissions: Actions > Read and write.
  2. Cloudflare > Workers & Pages > stonks-run-scheduler > Settings >
     Variables and Secrets > edit GITHUB_TOKEN > paste > Deploy.
