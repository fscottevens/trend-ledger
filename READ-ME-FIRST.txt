ABOUT scan.yml
--------------
The .github folder starts with a dot. Windows Explorer sometimes fails to
extract or copy dot-folders, which is why this file kept not updating.

If you cannot see a .github folder after extracting this zip:
  use the file named  scan.yml.COPY-INTO-.github-workflows
  rename it to        scan.yml
  and place it in     C:\Users\fscot\Documents\trend-ledger\.github\workflows\

To create that folder from Command Prompt if it does not exist:
  cd C:\Users\fscot\Documents\trend-ledger
  mkdir .github\workflows

To confirm the file is really there:
  dir /a .github\workflows
  findstr /C:"for attempt in" .github\workflows\scan.yml

That findstr must print a line. If it prints nothing, the file is not there.
